invocation, including clarify and recognized extension command phases. Core/extension
selection, runtime isolation, checkout-scoped persistence, repeated invocation ambiguity,
feature switching, delayed usage, private-state corruption and preview/apply behavior are

after an interrupted or repeated refresh. Raw transcripts and other authors' source files
are not rewritten. Source selection is subprocess-supervised with the existing maximum
15-second budget; capture retains its existing separate deadline.

- Cursor ledger directories receive best-effort owner-only POSIX permissions before

  is not claimed to be equivalent to POSIX mode bits.

- Explicit all-zero Cursor completions retain measured zeros. Missing segments remain
  unavailable and mixed measured/missing coverage remains partial.

- Unpriced-model diagnostics require measured nonzero usage; unmeasured activity and
  exact-zero observations no longer add spurious unknown-model warnings.

now forces reparsing. Permission-failure handling is tested on Windows. The POSIX mode

### Follow-up review: conflicting Codex histories

The requested follow-up review reproduced `--latest` selecting an older common-prefix
invocation when local and archived Codex session copies diverged later. Checkpoint
selection now rejects `conflicting-session-copies` before selecting any invocation,
including explicit timestamps. Manual mode returns an error; workflow mode warns
and continues. Neither mode writes a binding or refreshes feature reports in this case.
Ordinary capture retains its existing conservative shared-prefix accounting.

Four regression cases (latest/timestamp, manual/workflow) failed before the guard and
passed afterward. A fifth case verifies that a consistent archived prefix plus a longer
local history still selects the actual latest invocation. Checkpoint suite: **17 passed**.
Complete nonintegration suite with performance tests first: **484 passed, 8 deselected**
in 58.38 seconds. Ruff and whitespace checks passed. Integration wiring is unchanged;
the earlier six integration passes/two authenticated native skips remain the recorded
integration evidence. The previously documented default-order timing limitation remains.

- Extended CLI feature discovery to binding destinations because custom feature reports
