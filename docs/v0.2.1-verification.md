## Behavior covered

Explicit feature bindings override stale branch/timeline attribution for one observed
invocation, including clarify and recognized extension command phases. Core/extension
selection, runtime isolation, checkout-scoped persistence, repeated invocation ambiguity,
feature switching, delayed usage, private-state corruption and preview/apply behavior are
covered by sanitized fixtures. Claude, Codex and Cursor checkpoints exercise their real
adapters. Helper brainstorming skills retain the surrounding phase.

The after-specify workflow checkpoint is supplemental to native capture. Later phases
require their own explicit checkpoint. No session-wide default is inferred, and historical
repair remains separately selected. CLI reports discover custom feature destinations.
Rebinding retains prior destination inventory so obsolete local reports can be removed
after an interrupted or repeated refresh. Raw transcripts and other authors' source files
are not rewritten. Source selection is subprocess-supervised with the existing maximum
15-second budget; capture retains its existing separate deadline.
