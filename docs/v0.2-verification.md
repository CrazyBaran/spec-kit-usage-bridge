## Checks

- 449 nonintegration tests passed, including Claude oracle reconciliation.
- 49 vendor contract tests passed (also included in the nonintegration suite).
- Six real Spec Kit 1.0.12 install, dispatch, remove and release-archive tests passed.
- Two opt-in authenticated native-delivery smoke tests were skipped. Codex/Cursor
  automatic delivery remains manual/unverified; macOS/Linux delivery is unverified.

An independent whole-branch reviewer identified eight Important issues. One fix
pass added regression coverage for retained preview removal, SQLite WAL cache
invalidation, runtime deadlines, independent-session deduplication, reset counter
epochs, partial run coverage, uncertain phase intervals and native fork metadata.

contract and load the installed bridge ahead of a similarly named project module.
No minor findings were deferred. Publishing and merging have not been performed.

Follow-up review confirmed three remaining defects plus seven Copilot findings.
The fixes partition Codex usage by turn workspace, preserve explicit measured zero
in mixed Cursor ledgers, resolve worktree ownership, bound export reads and native
format probing, keep accounting quality separate from attribution confidence,
attribute activity-only runs with event evidence, render nullable call counts,
identify unpriced models by estimator reason, and reject malformed session entries.
Seventeen regression tests cover these findings and their missing-evidence cases.
A focused review also caught malformed exports hiding healthy ledgers and child
zero counts hiding missing parent usage. Both have regression coverage; measured
zero requires explicit evidence from every contributor in the same model bucket.

A second Copilot pass found four inline defects and three summary findings.
Sixteen additional tests cover conflicting-copy common prefixes (including three
copies), strict author/feature metadata and measurement validation, corrupt-source
isolation, subagent pricing diagnostics, unchanged-ledger cache stability, partial
bucket preservation, and mixed-runtime unpriced-model notes. Prefix-compatible
copies retain proven extensions; divergent copies retain only their common prefix.
Focused review added checks that missing observations still invalidate complete
buckets alongside field-level uncertainty and that clean command ledgers retain
their timestamps even when serializing them would reorder keys.

## Implementation rulings

1. Continue on the approved dedicated branch, using branch-level isolation rather
   than another checkout. Cost if wrong: other branch work could share the checkout.
2. Use the project virtual environment and workspace test temporary directories
   with pytest caching disabled because system tooling/default temp permissions
   are unavailable in the sandbox. Cost if wrong: test environment differs from CI.
3. Set Git's ceiling for temporary test projects so non-Git fixtures cannot inherit
   this enclosing repository. Cost if wrong: fixture Git behavior differs from users'.
4. Invalid-only counters are activity-only, not partial: no trustworthy measured
   usage exists. Cost if wrong: unsupported counter formats omit otherwise usable data.
5. Cursor ledgers use `cursor-ledgers/cursor` to match the unchanged vendor's layout.
   Cost if wrong: integrations expecting the initially proposed direct path need adjustment.
6. Authenticated and macOS/Linux native delivery remains unverified. Cost: users
   must refresh manually until native delivery has been established.
7. Cloud-only history and billing reconciliation remain outside the approved scope.
   Cost: inaccessible usage and actual subscription billing remain unavailable.
